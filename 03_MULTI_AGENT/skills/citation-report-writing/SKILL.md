# Skill: citation-report-writing

基于 evidence 列表写报告，并保持论点到来源的闭环。

## Rules

1. 只能引用证据列表中存在的编号，格式为 `[^N]`。
2. 关键判断、数字、趋势、对比、原因解释、结论性判断必须带 `[^N]`。
3. 不得引用 evidence 列表之外的来源。
4. 证据不足时写明“现有证据不足以确认”，不要用常识补成确定事实。
5. 如 evidence 冲突，必须说明冲突，而不是合并成单一事实。

## Repair Discipline

- 如果正文引用了不存在的编号，删除该引用或改写为证据不足。
- 如果已有 `## 引用` 章节缺少正文使用的编号，必须补齐。
- 不要为没有 evidence 支撑的段落伪造引用。
